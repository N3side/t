Нажмите комбинацию клавиш Win + R на клавиатуре.

Введите ncpa.cpl в появившемся окне "Выполнить" и нажмите Enter.

Нажмите правой кнопкой мыши по нужному сетевому интерфейсу (для проводного подключения или «Wi-Fi» для беспроводного).

Выберите пункт Свойства в появившемся меню.

В списке найдите строку ИП версии 4 (TCP/IPv4) и дважды кликните по ней (или нажмите один раз и выберите "Свойства" ниже).

Переставьте переключатель в положение "Использовать следующие адреса DNS-серверов".
